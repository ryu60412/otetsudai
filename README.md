# 🌟 おてつだいポイント PWA

お子さん向けの「おてつだいポイント」アプリです。  
iPad のホーム画面に追加して、普通のアプリのように使えます。

---

## 📱 できること

- ⭐ おてつだいをしたら +1 ポイント
- 🗺️ すごろく風の冒険マップで進捗を表示
- ☀️ あさチャレンジ（6:00〜7:30に起きたら +2 ポイント）
- 🎉 ゴール達成で紙吹雪の演出
- 🎭 6種類のキャラクター選択
- 🎯 目標ポイント数の変更（10〜100）
- 📴 オフライン対応（Wi-Fi不要で動作）

---

## 🚀 デプロイ方法（GitHub Pages）

### 手順1: GitHubアカウントを作成
1. https://github.com にアクセス
2. 「Sign up」からアカウントを作成（無料）

### 手順2: リポジトリを作成
1. 右上の「+」→「New repository」をクリック
2. Repository name: `otetsudai`（好きな名前でOK）
3. 「Public」を選択
4. 「Create repository」をクリック

### 手順3: ファイルをアップロード
1. 「uploading an existing file」リンクをクリック
2. ZIPから展開した以下の4ファイルをドラッグ&ドロップ：
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
3. 「Commit changes」をクリック

### 手順4: GitHub Pages を有効化
1. リポジトリページで「Settings」タブをクリック
2. 左メニューの「Pages」をクリック
3. Source で「Deploy from a branch」を選択
4. Branch で「main」→「/ (root)」を選択
5. 「Save」をクリック
6. 数分待つと URL が表示されます：
   `https://あなたのユーザー名.github.io/otetsudai/`

## 📲 iPadのホーム画面に追加する方法

### iOS 18以前の場合
1. iPad の **Safari** で上記URLを開く
2. 画面下部の **共有ボタン**（□に↑マーク）をタップ
3. **「ホーム画面に追加」** をタップ
4. 名前を確認して **「追加」** をタップ
5. ホーム画面にアイコンが追加されます！🎉

### iOS 26.1以降の場合
1. Safari で URL を開く
2. 右下の **「⋯」** をタップ
3. **「共有」** をタップ
4. **「⋯」（その他）** をタップ
5. **「ホーム画面に追加」** をタップ
6. **「追加」** をタップ

> ⚠️ **注意**: ホーム画面への追加は **Safari でのみ** 可能です。  
> Chrome や他のブラウザでは対応していません。

## 🔌 オフライン動作について

- 一度 Safari で開けば、Service Worker がファイルをキャッシュします
- 以降は **Wi-Fiなし・機内モードでも動作** します
- データは iPad 内の localStorage に保存されます

## 🧪 ローカルでテストする方法（PC）

Python がインストールされている場合：

```bash
cd otetsudai-pwa  # ファイルがあるフォルダに移動
python -m http.server 8000
```

ブラウザで http://localhost:8000 にアクセス

## ❓ トラブルシューティング

| 問題 | 解決方法 |
|------|----------|
| ホーム画面に追加できない | Safariを使っているか確認。Chrome等では不可 |
| アイコンが表示されない | icon-192.png を忘れずにアップロード |
| オフラインで動かない | 一度オンラインでページを開いてキャッシュを作成 |
| データが消えた | Safari の「Webサイトデータを削除」をすると消えます |
| 画面が更新されない | Safari でページを再読み込み（↻ボタン） |

## 📁 ファイル構成

```
otetsudai-pwa/
├── index.html      ← アプリ本体（HTML/CSS/JS一体型）
├── manifest.json   ← PWA設定ファイル
├── sw.js           ← Service Worker（オフライン対応）
├── icon-192.png    ← アプリアイコン（192x192）
├── icon-512.png    ← アプリアイコン（512x512）
└── README.md       ← この説明書
```

---

## ✨ カスタマイズのヒント

- `index.html` 内の絵文字やテキストを変更すれば簡単にカスタマイズ可能
- 目標ポイント数の初期値は `state.target` で変更
- キャラクターの追加は `char-grid` セクションに追加
