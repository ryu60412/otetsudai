# 🌟 おてつだいポイント PWA v2

お子さん向けの「おてつだいポイント」アプリです。  
iPad のホーム画面に追加して、普通のアプリのように使えます。

---

## 📱 できること

- ⭐ おてつだいをしたら +1 ポイント
- ⏪ まちがえたら -1 ポイント（もどすボタン・2回タップで確定）
- 👥 **複数の参加者に対応**（きょうだいで使える！）
- 🗺️ すごろく風の冒険マップで進捗を表示
- ☀️ あさチャレンジ（**時間を自由に設定可能**、+2 ポイント）
- 🎉 ゴール達成で紙吹雪の演出
- 🎭 6種類のキャラクター選択
- 🎯 目標ポイント数の変更（10〜100）
- 📴 オフライン対応（Wi-Fi不要で動作）

---

## 🆕 v2 の新機能

### 👥 複数参加者
- 最初に名前とキャラクターを登録
- 設定画面から参加者を追加・削除
- トップバーの「きりかえ」ボタンで参加者を切り替え
- ポイントは参加者ごとに独立管理

### ☀️ あさチャレンジ時間の変更
- 設定画面で開始時間・終了時間を自由に変更
- デフォルトは 6:00〜7:30

### ⏪ もどすボタン
- 間違えて押したときに -1 ポイント
- 誤操作防止のため 2回タップで確定

## 🚀 デプロイ方法（GitHub Pages・無料）

### 手順1: GitHubアカウントを作成
1. https://github.com にアクセス
2. 「Sign up」からアカウントを作成（無料）

### 手順2: リポジトリを作成
1. 右上の「+」→「New repository」をクリック
2. Repository name: `otetsudai`
3. 「Public」を選択 → 「Create repository」

### 手順3: ファイルをアップロード
1. 「uploading an existing file」リンクをクリック
2. ZIPから展開した以下のファイルをドラッグ&ドロップ：
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
3. 「Commit changes」をクリック

### 手順4: GitHub Pages を有効化
1. 「Settings」→ 左メニュー「Pages」
2. Branch:「main」→「/ (root)」→「Save」
3. 数分待つとURLが表示されます

### 手順5: iPadのホーム画面に追加
1. Safari で公開URLを開く
2. 共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
