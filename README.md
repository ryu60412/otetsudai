# おてつだいポイント PWA v4

## 機能
- 📱 iPad横画面1画面レイアウト（左:マップ / 右:おてつだい選択）
- ⭐ おてつだいの種類を選択（それぞれポイント設定可能）
- 🎵 BGM & 効果音（Web Audio API、ファイル不要）
- ⚙️ 設定はギアアイコンからモーダルで開く
- 👥 複数参加者対応
- 10ポイントごとに応援メッセージ
- ゴール達成で紙吹雪演出
- オフライン対応

## デプロイ
1. GitHubでリポジトリ作成（Public）
2. 6ファイルをアップロード → Commit
3. Settings → Pages → main / root → Save
4. iPadのSafariでURL → 共有 → ホーム画面に追加
