# 🌟 おてつだいポイント PWA v3

## 🆕 v3 の変更点

### ⭐ マイルストーン（10ポイントごと）
- マップ上の⭐が **10ポイントごと** に配置
- 各⭐マスに「いいかんじ」「がんばれ」などの短いラベル表示
- 10ポイント達成ごとに **応援メッセージがポップアップ**：
  - 10pt「いいかんじ！🌟」
  - 20pt「がんばってるね！💪」
  - 30pt「すごいぞ！⭐」
  - 40pt「えらい！👏」
  - 50pt「はんぶん すぎたよ！🎯」
  - 60pt「もっと いけるよ！🔥」
  - 70pt「あとちょっと！💨」
  - 80pt「もうすぐ ゴール！🏁」
  - 90pt「ラストスパート！🚀」
- ゴールまで残り10ポイント以内は「あとちょっと！」メッセージ

## 📱 その他の機能（v2から継続）
- ⭐ おてつだい +1ポイント
- ⏪ もどす -1ポイント（2回タップで確定）
- 👥 複数参加者対応
- ☀️ あさチャレンジ（時間変更可能）
- 🎉 ゴール達成で紙吹雪演出
- 📴 オフライン対応

## 🚀 デプロイ方法
1. GitHub で新規リポジトリ作成（Public）
2. ZIPから展開した6ファイルをアップロード
3. Settings → Pages → main / root → Save
4. 数分後にURLが表示される
5. iPadのSafariで開く → 共有 → ホーム画面に追加

楽しくおてつだいしましょう！ 🌟
