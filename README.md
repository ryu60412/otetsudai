# 🌟 おてつだいポイント PWA v3

## 📱 できること
- ⭐ おてつだい +1ポイント
- ⏪ もどす -1ポイント（2回タップで確定）

- 🗺️ すごろく風の冒険マップ
- ⭐ 10ポイントごとに応援メッセージ
- ☀️ あさチャレンジ（時間変更可能）
- 🎉 ゴール達成で紙吹雪演出
- 📴 オフライン対応

## ⭐ 10ポイントごとのメッセージ
- 10pt「いいかんじ！🌟」
- 20pt「がんばってるね！💪」
- 30pt「すごいぞ！⭐」
- 40pt「えらい！👏」
- 50pt「はんぶん すぎたよ！🎯」
- 60pt「もっと いけるよ！🔥」
- 70pt「あとちょっと！💨」
- 80pt「もうすぐ ゴール！🏁」
- 90pt「ラストスパート！🚀」
- ゴール残り10pt以内は「あとちょっと！」

## 🚀 デプロイ方法
1. GitHub で新規リポジトリ作成（Public）
2. ZIPから展開した6ファイルをアップロード
3. Settings → Pages → main / root → Save
4. 数分後にURLが表示される
5. iPadのSafariで開く → 共有 → ホーム画面に追加

楽しくおてつだいしましょう！ 🌟
